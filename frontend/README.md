# Frontend

React frontend application for the block explorer built with Vite.

## Available Scripts

- `npm run dev` - Start the development server (default port: 3000)
- `npm run build` - Build the application for production
- `npm run preview` - Preview the production build
- `npm start` - Alias for preview

## Features

- React 18
- Vite for fast development and building
- Proxy configuration to connect to backend API
- Responsive block display
- Health check integration

## Development

The frontend automatically proxies `/api` requests to the backend server running on port 3001.
